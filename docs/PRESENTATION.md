## 1. 문제 (1'30")

**한 문장으로 시작합니다.**

> "학사 문의는 같은 질문이라도 **학생마다 답이 다릅니다.**"

**실례를 바로 꺼냅니다. 이게 제일 셉니다.**

> "이화여대 컴퓨터공학은 2024년에 소속이 바뀌었습니다.
>  2023년까지는 엘텍공과대학 소프트웨어학부 컴퓨터공학**전공**,
>  2024년부터는 인공지능대학 컴퓨터공학**과**입니다.
>
>  그래서 2022학번과 2025학번은 **소속도, 교육과정도, 졸업요건도 다릅니다.**
>  '졸업요건 뭐예요?' 라는 똑같은 질문에 답이 두 개인 겁니다."

→ 가정으로 만든 시나리오가 아니라 **실제로 일어난 일**이라는 점을 강조.

**그리고 축이 둘이라는 걸 못 박습니다.**

> "누구에게 적용되는가(학번·학과)와, 언제부터 적용되는가(개정일·시행일).
>  이 둘을 동시에 따져야 답이 나옵니다."

## 4. 시연 (3'30") ★ 핵심

**미리 녹화해 두세요.** 현장 네트워크·LLM 응답 지연으로 망치면 복구가 안 됩니다.
녹화본을 틀고 말로 설명하는 방식을 권장합니다.

### 순서

| | 화면 | 말할 것 |
|---|---|---|
| ① | 학생 접수 | "학생이 문의를 넣습니다" |
| ② | 담당자 대시보드 | "담당자 화면에 미처리로 올라옵니다" |
| ③ | **Agent 실행** | "근거를 찾습니다" |
| ④ | **근거 패널** | "원문 그대로, 출처와 함께 보여줍니다" |
| ⑤ | **확인되지 않은 항목** | **"여기가 핵심입니다"** |
| ⑥ | 담당자 판단 | "사람이 판단합니다" |
| ⑦ | 초안 → 수정 → 등록 | "담당자가 검토하고 등록해야 학생에게 갑니다" |
| ⑧ | 학생 화면 | "학생이 최종 답변을 확인합니다" |

### ⑤에서 멈추고 말할 것

> "학수번호 20481은 자료구조, 전공필수 3학점으로 **확인됐습니다.**
>  그런데 39144는 교과과정표에서 **찾지 못했습니다.**
>
>  이때 저희 시스템은 '인정 불가'라고 하지 않습니다.
>  **'확인되지 않았다'고 그대로 말합니다.** 자료에 없는 것과 안 되는 것은 다르니까요.
>  판단은 담당자가 합니다."

→ **이 한 장면이 발표 전체에서 제일 중요합니다.** 환각 질문을 미리 막습니다.

## 예상 질문과 답

**Q. 학생 대기 시간이 줄어드나요?**
> 직접은 아닙니다. 학생은 여전히 전화합니다. 담당자의 1건 처리 시간이 줄어 통화 회전이 빨라지는 간접 효과입니다.

**Q. 비슷한 연구가 이미 있지 않나요?**
> 있습니다. 고려대가 올해 8월에 학사 상담 챗봇 논문을 냈습니다(hoBIT). 다만 그건 **학생용 챗봇**이고 **학번 축만** 다룹니다. 저희는 **담당자용 업무 시스템**이고 **시행일·경과조치까지** 다룹니다.

**Q. 틀린 답을 하면요?**
> 근거 없이 답하지 않습니다. 확인되지 않은 항목은 그대로 표시하고, 최종 등록은 담당자가 눌러야 학생에게 갑니다.

**Q. 왜 챗봇이 아닌가요?**
> 업무용이기 때문입니다. 대화창은 처리 상태·대기열·기록이 남지 않습니다. 담당자가 쓰는 건 창구가 아니라 업무 흐름입니다.

**Q. 자료가 오래된 건 어떻게 아나요?**
> 게시일·개정일·시행일을 따로 저장합니다. 알 수 없으면 비워 두고 '확인 필요'로 표시합니다. 최신 게시물이라는 이유만으로 자동 선택하지 않습니다.
